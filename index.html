大模型工具调用后训练与奖励机制分析

Qwen2.5-0.5B

2026.10
GitHub: github.com/mxzl1089/toolcall-rlvr
PyTorch Transformers TRL PEFT QLoRA GRPO
  • 后训练实现：面向自然语言到结构化工具调用任务，参考 ToolRL，在 4GB 单卡上完成 QLoRA-SFT 与 GRPO；采用回答部分监督、梯度累积与梯度检查点，记录训练指标与模型输出。
  • 数据与评测：按工具名隔离训练、验证和测试集，完成数据去重与 schema 校验；独立实现工具调用严格评测，支持并行调用换序、重复次数保留及参数类型检查，并按调用数量、工具名、参数键和值分类分析错误。
  • 奖励诊断：从共同 SFT 起点开展继续 SFT、稀疏与分层 GRPO 三种子对照，平均严格一致率分别为 44.23%、42.77%、41.93%；通过配对 bootstrap、同候选重评分及屏蔽消融，发现分层奖励提供更多组内区分信号，但相较稀疏奖励未取得显著性能优势。
  • 扩展训练：保持共同 SFT 起点与分层奖励不变，使用完整的 973 条训练样本训练 2 轮；单种子实验中，最终模型在固定 159 题历史测试集上的严格一致率由 40.25% 提升至 48.43%（+8.18 个百分点），通过固定验证集跟踪训练过程，按预定终点评测最终性能。

像素级强化学习与策略可解释性分析

Flappy Bird

2026.08 — 2026.09
GitHub: github.com/mxzl1089/flappy-bird-interpretability
Python PyTorch pygame DQN PPO NumPy TensorBoard

参考 DeepLearningFlappyBird 的 TensorFlow 实现，基于原游戏环境使用 PyTorch 重实现并加入目标网络，扩展 PPO 对照实验，分析策略的跨难度表现与可解释性。

  • 算法实现：以连续 4 帧 80×80 二值图为输入、拍翅与否为动作，实现 CNN-DQN 与 Actor-Critic PPO，分别开展约 200 万环境步训练；DQN 引入经验回放与目标网络，PPO 使用 GAE 和策略比率裁剪，支持无窗口运行及模型/优化器状态恢复。
  • 训练评测：对 40 个 DQN、38 个 PPO 检查点各评测 10 局，共 780 局，统计均值与 95% bootstrap 区间；最高均分分别为 118.8 / 2158.9，结合得分、Q 值及策略熵跟踪训练表现。
  • 跨难度泛化：冻结 DQN，在管道间隙 100/120/150 的探索性评测中观察到均分非单调变化（187.5 / 357.8 / 135.5）；据此提出“容错空间增加与观测分布漂移共同影响表现”的机制假说。
  • 事后可解释性：结合输入归因与反事实位置干预，分析策略的时空敏感性；小鸟归因密度在管道周期内由 0.92 升至 9.29，死亡前 30 帧内峰值达 14.81；在所测干预中竖直位移改变拍翅决策，同幅横向位移影响较小。
  • 可解释代理模型蒸馏：基于 LMUT 思路，以离线线性叶模型树蒸馏 DQN 的动作价值，通过分裂路径与区域高亮分析局部决策；71% 的分裂位于最新帧，前 20 个高影响像素中 12 个位于小鸟区域。
  • 解释一致性：对比代理树的块级特征影响与冻结 DQN 的输入遮挡敏感度；在树影响非零的 87 个区块上测得 Spearman ρ=0.65，为两种分析方法在关键区域上的一致性提供支持。
